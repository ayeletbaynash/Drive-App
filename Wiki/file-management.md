# File Management and Operations

This page explains how to navigate the AweSoMe Drive system and manage your files and folders across all platforms.
##  System Navigation (App Pages)
The system is optimized for both platforms, allowing you to filter and view files based on your needs:

### Web Interface
All navigation options are easily accessible through the **Sidebar Menu**.

### Mobile App
* **Bottom Navigation Bar:** Quick access to **Home**, **My Drive** (Files), **Shared**, and **Starred**.
* **Side Drawer Menu:** Access **Recent** files and the **Trash** by opening the side menu (hamburger icon).

### Page Descriptions:
* **Home:** Displays everything you have access to (your files + shared files).
* **My Drive:** Only shows files and folders that you own.
* **Shared with Me:** Files and folders that other users gave you permission to access.
* **Recent:** Shows files sorted by the last update time (newest first).
* **Starred:** Quick access to all items you have marked with a star.
* **Trash:** Displays deleted items that can still be restored or permanently removed.

## File & Folder Operations

### Permissions & Dynamic Actions
AweSoMe Drive uses a dynamic permission system. The actions available for each file or folder depend on your relationship with that item (Owner, Editor, or Viewer). To ensure security, the action menu only displays operations you are authorized to perform.

**How to access actions:**
* **General Actions:** All operations (Rename, Share, Move, etc.) are accessed by clicking the **three dots (⋮)** icon next to each item.
* **Creating New Items:** To create a folder, text file, or upload a file, click the **Plus (+)** button located on the screen.

---

### 1. Universal Actions (Available to Everyone)
These actions are available to any user who has access to the file/folder:
* **View Content:** click to view text content or open a folder.
* **File Details:** View metadata such as creation time, last update, owner, and permissions.
* **Add to Favorites (Star):** Mark items for quick access in the "Starred" tab.
* **Download:** Download a single file or an entire folder.
* **Make a Copy:** (Files only) Create a duplicate of an existing file.
* **Move To:** Relocate an item to a different folder in the system.

### 2. Editor Actions (Requires "Write" Permission)
Available to the Owner or users granted "Write" access:
* **Edit Content:** Update the text inside an existing text file.
* **Replace Image:** Swap an existing image with a new one from your device.
* **Rename:** Change the name of a file (Folders can only be renamed by the Owner).

### 3. Owner Actions (Owner Only)
These critical actions are reserved strictly for the person who created the item:
* **Share:** Manage access permissions and invite other users to collaborate.
* **Rename Folder:** Only the owner can change folder names to maintain structure.
* **Remove:** Move the file or folder to the **Trash**.

### 4. Trash Management (Owner Only)
Once an item is in the Trash, the owner has two exclusive options:
* **Restore:** Move the item out of the Trash and back to its original location.
* **Permanent Delete:** Fully and irreversibly remove the item from the system.



---

### 5. Creating and Uploading (The "+" Menu)
* **New Folder:** Create a custom folder to organize your workspace.
* **New Text File:** Create a text file directly in the app.
* **Upload File:** Upload PDF, text, or image files from your computer or mobile device.
* **Camera Capture (Mobile Only):** Use the **Camera button** to take a photo directly within the app and upload it instantly to your drive.
